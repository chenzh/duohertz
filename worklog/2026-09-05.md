# 2026-09-05 工作日志

## 已完成

- **谱面跟拍感根治（105 首 × 3 档 = 315 张谱全量重出）**：用户反馈《Satin Underpass》"不跟拍"。

  - **根因**：`scripts/beatscape-chartgen.py` 的 `select_onsets()` 排序键是**纯能量** `key=lambda x: -x[2]`。onset 检测密度约 11/s，而 90 BPM 的八分网格只有 3/s——"最响的 onset"大量落在拍与拍之间的微位置上。结果是**每个音都有声，但相邻间隔忽长忽短**，玩家锁不住脉冲，听感就是"不跟拍"。注意这既不是 onset 检测失准，也不是 BPM 检错。
  - **修法**：排序键改为 `score = norm(energy) + grid_w × grid_affinity(t, beat, offset)`。`grid_affinity` 按到最近整拍的距离给权：整拍 1.00 / 八分 0.78 / 十六分 0.50 / 格间 0，容差 `GRID_TOL_SEC = 22ms`（取 onset 检测抖动的量级）。能量归一化到 0..1 后仍是主导项，网格只是加成，所以不会出现"贴格但听不见"的音符盖过"响亮但离格"的音符。
  - **`grid_w` 定参**：在三首不同 BPM 曲上按档扫描，约束是**响度 x ≥ 0.95**（选中 onset 平均能量 / 全曲 onset 平均能量）。低于这个值就会出现踩空感——音符踩在听不见的地方。定出 **easy 0.60 / standard 0.50 / hard 0.40**：easy 最贴拍（新手要能锁住脉冲），hard 只轻度拉一把、保留切分加花。
  - **`enforce_peak_nps` 同步改**：超密度删音符时，优先删窗口内**最不贴格**的那个（而不是原来的"取中间"），保留节奏骨架。加了护栏——只有窗口内贴格程度**有差异**时才按 aff 挑，否则退回原行为；否则全部离格时会退化成"删最早的"，白白改变既有谱面。
  - **验证**：网格内% 中位 easy 46.7 → **81.7**、standard 32.6 → **77.1→79.6**、hard 33.9 → **97.1**（hard 按十六分格计，见下条）。《Satin Underpass》easy 25.2% → **82.7%**，响度 x 0.96。音符数最多 -4.7%；仅 3/3/4 首轻微回退。门禁 tsc 0 / vitest 122。

- **跟拍感诊断工具 `scripts/beatscape-chart-gridfit.py`**：为量化"跟拍"新建。指标是**最优相位下的网格内%**——衡量"音符是否构成一个规整的脉冲网格"，而不是"对齐到某个绝对时钟"，因为玩家感知的是间隔规不规律、能否预期下一个音。相位用**差分数组区间投票**搜索，O(n + steps)；对每个候选相位重算一遍是 O(n·steps)，315 张谱会跑到分钟级。

  - **这个工具自己错了两次，两次都差点误导到改谱**（值得记住：先验证尺子，再相信读数）。
    1. 最初拿 `beat_map.first_beat_ms` 当相位基准，得出 easy 中位"31%"（以为很糟）。后来发现 `first_beat_ms` **运行时根本不读**——`PlayField` 只读顶层 `audio_offset_ms`，而生成器恒输出 0；它只是元数据，检测还常偏（bs-s5-01 偏 2 秒：原相位下 21.7% 贴格，最优相位 84.0%）。改成搜索最优相位后，真实基线是 **46.7%** 而非 31%。
    2. 又给 hard 用八分格判定，但 hard **合法使用十六分加花**。低速曲 hard 在八分格下 53.0%、十六分格下 **95.9%**——差的 43pp 全是尺子的错。改为按档位选判定网格（`TIER_GRID_PER_BEAT`：easy/standard 每拍 2 格、hard 4 格），并在脚本头部写明代价：网格越密判定越松，随机基线八分约 24%、十六分约 48%，**不能跨档横向比较绝对值**。
  - **新增 `--bpm-scan`**：在 declared bpm ±8% 内搜最适 bpm，用来回答"低分是谱的问题还是 bpm 检错了"。bpm 只要偏一点，整条网格就会随曲子推进而旋转，再好的谱也读成低分。
  - **残留低分的结论（已写进脚本头部"看到低分怎么办"）**：既不是 bpm 也不是谱，是**音频本身不规整**。三重验证：① bpm 扫描——12 首抽查里 10 首最适 bpm 与档内相差 <0.1%，最差几首即便用最适 bpm 也只涨 1.4~5.4pp；② onset 池上限——弱曲只有 26~46% 的 onset 落在最优网格上（对比《Satin Underpass》池里 39.3%，但谱能挑到 82.7%）；③ grid_w 扫描——从 0.6 拉到 4.0，这些曲只涨 0~7pp（bs-p4-09 反跌 4.5pp）。属于音源硬上限，改谱无解。
