## IP 战略与 7 District 角色设计稿（追加）

收到用户的方向调整：「游戏只是载体，人物是 IP、音乐是 IP」。基于已知约束做了一次战略对话，落地物如下。

### 关键决策（已问已答）

| 维度 | 决策 | 影响 |
|------|------|------|
| 音乐 IP 变现路径 | **只做自有产品内用**，不对外授权 | 不需要补人类创作性证据链 / 母带登记，但**必须注册商标**作为护城河 |
| 角色系统 | **7 个 District 角色**（VOLTA / STATIC / PRISM / EMBER / RIVET / GLIDE / HALO）| 与现有 85 首曲库 + 7 District 配色 + 5 曲风配额天然咬合，不另起世界观 |
| 衍生品第一批 | **只做角色设计稿**，不碰商品 | 产出来就是 7 张 District 角色设计稿（1200×1400 PNG）+ IP 战略文档 |

### 重要风险与发现

- **音乐 IP 弱**：编曲层（SA3 MLX 生成的旋律）在美中多数司法辖区不受著作权保护。录音制作者权（母带）可用但不是"曲"。商标才是真正护城河。已要求必须先注册 17 个商标（BeatScape + RESONANCE + 7 District + 7 角色代号）。
- **IP 与现有视觉策略的对冲**：RESONANCE-VISUAL-PLAN §1.1/§8 写「BeatScape 本就无角色，保持无角色」。要做 IP 就要改这条，但 IP 反而要更狠地拉开差异化（look-and-feel 风险被衍生品放大）—— Tetris v. Xio 教训。
- **PRD 同步缺口**：PRD v1.2 定位是「音乐生成 API 服务」，没提 IP。已升级为 v1.3，新增 §21 IP 资产线章节 + §19 #4/#6。
- **图像生成服务连通性**：试水时 ImageGen 4 次都是 TLS 握手失败，临时改为 SVG/PNG 矢量管线交付（项目既有封面管线一致），最终效果 7 个角色差异性在 64px 剪影上可读。
