**① 拖拽性能（原最大问题）**

**React 细节坑（已规避）**
`paint()` 用 `textContent` 改写时间文本。按 DOM 规范 `string replace all`，只有当该 span 恰好有**唯一一个 Text 子节点**时才会复用原节点；若写成 `{a} / {b}`（3 个文本节点），`textContent=` 会移除并新建，React 持有的 text node 脱钩 → 拖拽后时间显示静默冻死。故时间 span 写成单一插值 `{`${fmt(time)} / ${fmt(dur)}`}`，气泡 span 同理单行写法。

### UI 视觉审计 → A 档改造（滚动揭示 / 封面交互层 / Hero 漫画画框）

**背景**：先做了一轮全站 UI 审计，结论是动效与完成度分布极不均 —— 只有结算页有动效（grade 盖章 / 分数滚动 / 判定柱生长 / honor pop），其余 7 个页面零动效、硬切。共列 12 项分四档，用户选了 A 档全套。

**硬约束**：PRD §7.5 v2.0 RESONANCE = 扁平 / 硬边 / 漫画语言，**明确禁止霓虹光晕**（`--shadow-glow`/`--glow-accent`/`--glow-mint` 都是被刻意"退休"成 `none` 的）。所以"炫酷"只能走漫画技法（网点 / 集中线 / 硬投影 / skew / 分镜框），不能加 glow / blur。

**改动**
- 新增 `apps/beatscape/src/components/useReveal.ts`：IntersectionObserver 滚动揭示，`useReveal(key?, selector?)`。
- 接入：`Home.tsx`（按段，key=`tracks.length`）、`Library.tsx`（`.track-card`，key=`tracks.length`）、`Characters.tsx`（`.character-card`，静态列表无 key）。
- `styles.css` 追加 A 档整块（~150 行）：揭示动效 + 网格错峰 + halftone 封面交互层 + Hero 字幕条 / ON AIR 标签 + 各自的 reduced-motion 兜底。
- `HomeHeroPlay.tsx`：新增 `!live` 分支下的 ON AIR 标签。

**三个值得记住的设计决策**
1. **fail-safe 优先**：隐藏态只由 JS 加的 `.reveal-armed` 驱动，元素默认可见。异步加载的、或 hook 没扫到的节点只会"直接可见"，绝不会卡在 opacity 0。
2. **Library 的 key 用 `tracks.length` 而不是 `filtered.length`**：用后者的话每次搜索按键都会重扫、把已显示的行重新 arm，输入时会闪。
3. **`router.Link` 不透传任意 props**（只认 to/children/className/onClick/title/aria-label），卡片挂不上 `data-reveal` → hook 支持可选 selector 按 class 选，CSS 规则也不挂 `[data-reveal]` 前缀（挂了会静默失效，我第一版就踩了）。

**CSS 两个坑**
- 位移用独立 `translate` 属性而非 `transform` —— 用 `transform` 会跟 `.track-card:hover { transform: translate(-2px,-2px) }` 打架，且 `.reveal-armed.is-visible`（特异性 0,2,0）会反过来盖掉 hover 的位移。揭示完成置 `none` 而非 `0 0`，避免 ~80 个元素长期背着 containing block / 层叠上下文。
- **顺手修 bug**：`.track-hero-cover` 原为 `box-shadow: var(--shadow-card), var(--shadow-glow)`，而 `--shadow-glow` 是关键字 `none`、`none` 不能出现在逗号列表里 → **整条声明非法，大封面一直没有阴影**。改为 `box-shadow: var(--shadow-card)`。

**验证**：`tsc --noEmit` 干净 · `vitest run` **120 passed** · `vite build` 绿（首屏 JS gzip 103.89 KB）· dev server 冒烟（`/beatscape/` 200、`useReveal.ts` 200、产物 CSS 含新规则）。另核对全站 4 处 `position: fixed`（`.play-bg` / `.neon-layer` / `.mobile-tabbar` / `.home-intro-backdrop`）均不在被揭示元素内，不会被 `translate` 生成的 containing block 破坏。
