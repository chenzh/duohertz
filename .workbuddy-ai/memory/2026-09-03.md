## AudioBar 播放按钮死锁修复（commit `582b598`）
- **坑**：首页 `<AudioBar preload="none">` 的播放按钮被永久 disabled。原因是播放按钮门禁写成 `disabled={!ready && !dur}`，而 `preload="none"` 下浏览器不预拉元数据 → `onLoadedMetadata`/`onCanPlay` 都不触发 → `dur=0`、`ready=false` → 按钮禁用；而「点播放」恰恰是唯一能触发加载的动作 → 死锁。
- **教训**：`<audio>`/`preload="none"` 场景下，**不要用「元数据已加载」去 gate 播放按钮**，会自锁。正确做法是只用 `src` 判空，元数据迟到由 `readyState > 0` 在具体 seek 处兜。Track 页用默认 `preload="metadata"` 所以没暴露——**这类 bug 只会在某一个调用点显现，改共享组件务必把所有调用点的 props 差异过一遍**。
- 顺带清掉因此失效的 `ready`/`setReady`/`onCanPlay` 死状态。

## Play 页 HUD 双层重叠 bug 修复
- **症状**（用户截图）：Play 页同时显示两套 HUD 元素：
  - 左上 SCORE 卡（橙色硬边）= PlayHud DOM 里的 `.hud-track`；紧贴下方又出现 "0" 黑底小卡 = renderLoop 旧版内置 score 面板。
  - 右上 0.00% 黑底小卡 = renderLoop 旧版内置 accuracy 面板。
  - 左中竖排 "SIGNAL" 文字 = renderLoop 旧版 SIGNAL gauge 旁边的旋转 -90° 标签。
  - 顶中"S / ‖ / ▶"——.hud-signal "SIGNAL" pill 居中时被 .pause-btn 居中覆盖，只露左 S。
  - 底部 PERFECT/GREAT/GOOD/MISS = PlayHud `.hud-judges`（这一组没重复，是对的）。
- **根因**：
  1. **双 HUD 重叠**——B-1 commit `417ece9` 引入 PlayHud（DOM）做"漫画分镜"风格 HUD，但 `renderLoop.ts` 里的旧 score/accuracy/SIGNAL gauge 绘制段（`draw()` line 727-792）没删掉，对局页两套同时画。`PlayField` 传 `statsRef` 时挂载 PlayHud = 「DOM HUD + canvas 旧 HUD」叠加。
  2. **pause-btn 遮挡 .hud-signal**——`.pause-btn` 用 `top:10px left:50% transform:translateX(-50%)` 居中，`.hud-signal` 也是 `top:14px left:50% skewX(-6deg)` 居中，两个 z-index:12 vs 6 但都顶在屏幕中央，pause-btn 几乎完全盖住 SIGNAL pill。
- **修复**：
  1. `PlayfieldRenderContext` 加 `useComicHud: boolean` 字段；`createPlayfieldRenderer` 拿到后在 `draw()` 里把整段 729-792（score 卡 / accuracy / SIGNAL gauge + 旋转文字）包进 `if (!useComicHud) { ... }`。combo 中央大数字、HP 条、key hints、milestone flash、floating score pops 都不动——那些 PlayHud 没重复。
  2. `PlayField` 加 `useComicHud?: boolean` prop（默认 `useComicHud ?? !!statsRef`），用 `useComicHudRef` 缓存再读，传给 renderer —— 不进 rAF effect 的依赖，避免「中途切换 comic HUD 模式」时整个 rAF 被销毁重建（连带重跑 halftone pattern + note sprite 预渲染，玩家会看到一帧卡顿）。
  3. `.pause-btn` 挪到 `top:14px right:14px`（不再 left:50% + translateX），让 `.hud-signal` 独占顶中。`.hud-combo`（combo>0 才显，默认 opacity:0）也占 right:14px，pause-btn z-index:12 在 `.play-hud`(z:6) 之上，两者同时出现时 combo 会被 pause 盖住——权衡后选了"暂停键永远可点"。
- **未做**（不影响用户报的 bug）：
  - HP 血条只有 `mode === "arcade"` 画；PlayHud 没画 HP。后续若想统一，可以加 `.hud-hp` 进 PlayHud。
  - 中央下落菱形 (lane 0 红/lane 2 黄/lane 3 蓝) 来自 renderLoop 的 `drawNote`，是 note 落体动效，不是 bug。
  - `MISS=12` 是用户没按导致的真实 miss（游戏已开跑，conductor 播放 + session.tick 跑着），不是 bug。
- **教训**：**DOM HUD + canvas HUD 不能并存**——加新层时必须先把旧层显式关掉，标志位（如这里的 `useComicHud`）要钉到 props 推导上（`!!statsRef`）而不是各处手填，避免漏传。顶中位置是稀缺资源，`.pause-btn` / `.hud-signal` / 中央大数字 三选一保留——`.hud-signal` 改成顶中独占，pause 退到右上。
