## AudioBar 播放条优化（apps/beatscape）

- **关键模式（可复用）**：拖拽类 UI 的优化范式 = `pointerdown` 缓存 `getBoundingClientRect()` → 拖拽中通过 ref 直写 DOM → `pointerup` 才 `setState` 提交一次；同时让原生高频事件（timeupdate/progress）在拖拽期早退，避免回写抖动。
- **React 坑（务必记住）**：用 `textContent` 手动改写 React 渲染的文本时，目标元素必须只有**一个 Text 子节点**（写成 `{`${a} / ${b}`}` 单插值，不能 `{a} / {b}`）。否则按 `string replace all` 规范会新建 Text 节点，React 持有的旧节点脱钩，之后所有文本更新静默失效。

## A 档已实施（useReveal + 封面交互层 + Hero 画框）
- 新增 `apps/beatscape/src/components/useReveal.ts`：`useReveal(key?, selector?)`，IntersectionObserver 滚动揭示。
- **三个可复用的决策**：① 隐藏态只由 JS 加的 `.reveal-armed` 驱动、元素默认可见 → **fail-safe**，未扫到的异步节点不会卡在 opacity 0；② 列表页 key 用 `tracks.length` 而非 `filtered.length`（后者会逐键重扫、搜索时闪烁）；③ **`router.Link` 不透传任意 props**（只认 to/children/className/onClick/title/aria-label），所以卡片挂不了 `data-reveal` → hook 支持 selector 按 class 选，CSS 规则也**不能**挂 `[data-reveal]` 前缀，否则静默失效。
- **CSS 坑**：揭示位移必须用独立 `translate` 属性，不能用 `transform` —— 否则 `.track-card:hover { transform: translate(-2px,-2px) }` 会被 `.reveal-armed.is-visible`（特异性更高）顶掉。揭示完成置 `translate: none` 而非 `0 0`，免得 ~80 个元素长期背着 containing block / 层叠上下文。
- **顺手修的 bug**：`box-shadow: var(--shadow-card), var(--shadow-glow)` 里 `--shadow-glow` 是关键字 `none`，`none` 不能出现在逗号列表 → **整条声明非法**。凡是把 "退休" 成 `none` 的 token 用在多值属性里都会踩这个坑，值得全局排查。
- 门禁：`tsc` 干净 / `vitest 120` / `vite build` 绿（首屏 JS gzip 103.89 KB）/ dev 冒烟 200。
