- **Satin Underpass「不跟拍」根因定位（未修，只诊断）**：`bs-s6-13`，90 BPM。
  已排除：谱面时间轴没错（三档 note 与当前音频做 ±1.2s / 10ms 分辨率互相关，best lag ≈ 0ms，谱和音频对齐）；`Conductor` 用 `AudioContext.currentTime` 作权威时钟、倒计时同时间轴、suspend 缺口补偿都对；`casualSpeed` 只缩 `approachSec`（提前量），不动判定时刻。

  **真正原因**：`scripts/beatscape-chartgen.py` 的 `select_onsets()` 排序键是**纯能量** `key=lambda x: -x[2]`，**完全没有"贴网格"项**。onset 检测密度约 11.4/s，而 90 BPM 的八分音符网格只有 3/s，所以"最响的 onset"大量落在拍与拍之间的尴尬微位置。结果：每个 note 都踩在真实声音上，但**间隔忽长忽短，没有可锁的脉冲** → 手感就是"不跟拍"。

  **量化指标**（临时脚本 `/tmp/gridfit.py`，比之前的 groove-check 有区分度）：`间隔规整%` = 相邻 note 间隔落在 1/2/4/8 拍 ±12% 内的占比。全目录 easy 档区间 **5.6% ~ 59.4%**。
  - Satin Underpass：中位离格 12.4% 拍（≈83ms）、网格内 25.2%、**规整 11.2%**（倒数约 15/105）
  - Midnight Haze（玩着正常）：离格 12.1%、网格内 30.7%、规整 12.2%
  - 最差：Lounge Ember 5.6%、Satin Nightline 6.7%；最好：Skyline Cadence 59.4%、Midnight Rhapsody 58.0%

  **结论**：这是**全目录的通病**（中位约 25–30%），Satin Underpass 只是最糟的一批，不是特例。修法是给 `select_onsets` 的打分加 beat 亲和力项（`score = energy_norm*(1-w) + grid_affinity*w`），或两趟法：先按网格锚出骨架，再用高能量离拍 onset 做加花。改完要全量重生成 315 张谱 + 跑一遍 gridfit 回归。
