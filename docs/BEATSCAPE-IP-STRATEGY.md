## 0. 一句话定位

BeatScape **不是一个游戏 + 一堆 BGM**——它是 **一个角色 IP 矩阵 + 一个音乐 IP**：
- 角色 IP：7 个 District × 7 个原创角色，挂载在已有世界观与曲风配额上。
- 音乐 IP：85+ 首 AI 原创 BGM，**仅作自有产品内用**（游戏 BGM / 周边视频配乐 / 品牌内容），**不**做对外授权（sync / 广告 / 流媒体 / 二次分发）。

这两条 IP 的法律强度差别巨大，文档先讲清楚。

## 1. 音乐 IP — 实际能站住的是两样东西

| 资产 | 强度 | 依据 | 备注 |
|------|------|------|------|
| **录音制作者权**（母带本身） | ✅ 可用 | `clip-game` / `stitch-stream` / `beatscape-ingest-stream.py` 的人工参数决策（切片起点、循环长度、响度、母带重混）可作为人类创作性介入的证据 | 中国：「有人类智力投入的 AI 辅助生成物」已有判例支持（深圳南山、北京互联网法院相关判决）。美国：纯 AI 仍不受保护，但录音制作者权独立成立 |
| **商标 / 品牌** | ✅ 强 | 曲名、虚构艺人名、BeatScape、RESONANCE、各 District 名 | 衍生品最硬的护城河，必须注册 |
| **编曲著作权** | ⚠️ 弱 | 美国版权局立场：纯 AI 生成无人类作者 → 不受保护（Thaler v. Perlmutter 及后续 Guidance）。中国标准不统一 | 不可作为对外授权的版权基础 |
| **原曲旋律 / 采样** | ✅ 无 | 引擎许可干净（SA3 Community License / ACE-Step MIT），无任何第三方旋律或采样 | 维持现状即可 |

### 1.1 边界（决策记录）

**对外授权一律不做**。任何把母带授权给第三方用于以下场景的请求都拒绝：
- 影视 / 广告 / 短视频配乐的 sync
- Spotify / Apple Music / NetEase 等流媒体上架
- 第三方游戏 / 应用再分发
- 任何形式的商品化重制（实体 CD、贴牌 BGM 库等）

理由：纯 AI 生成的编曲在大多数司法辖区不受著作权保护，对外授权时对方律师必查 human authorship warranty，我们拿不出。强行授权会同时暴露买方法律风险和我方法律风险，**得不偿失**。

**自有产品内用**，已具备的全部资源（85+ 母带 + 90+ 拼接版 + 50+ 游戏切片）继续用于：
- BeatScape 游戏内 BGM
- 周边短视频 / 角色 PV / 直播回放配乐
- 品牌官网 / 社交媒体内容
- **未来**：角色语音 / 互动音频（v0.2+）

**什么时候可以重新评估**：等 (a) 美国/中国司法环境对 AI 著作权有更明确的边界，或 (b) 我们引入人类创作性介入（编曲师人工 remix / 现场录音 / 人声 demo）后产生**新**的可保护录音制作者权。

### 1.2 商标注册清单（**阻塞项 — 见 §6**）

按"先注册，再使用"原则，下列标识必须先注册商标：
- **BeatScape**（主品牌）
- **RESONANCE**（风格副品牌）
- 7 个 District 名（**Pulse Core** / **Night Grid** / **Glass Rim** / **Afterhours Lane** / **Chrome Yard** / **Slide District** / **Skyline Hook**）—— 7 个独立商标
- 7 个角色代号（VOLTA / STATIC / PRISM / EMBER / RIVET / GLIDE / HALO）—— 7 个独立商标

合计 **17 个商标**，建议分两批：主品牌 + District（1 类、9 类、41 类）首批；角色代号（9 类、14 类、25 类、28 类）次批。

## 2. 人物 IP — 7 个 District 角色矩阵

把角色挂在 7 个 District 上，**不是另起炉灶**，而是用现有 85 首曲库 + 7 District 配色 + 5 曲风配额 + 4 听感 Vibe 的结构当骨架。每个角色 = 一个 District 的"夜班人格"。

### 2.1 角色总表

| 代号 | District | 曲风 | Vibe | 职业 / 锚点 | 标志物 | 主色 |
|------|----------|------|------|-------------|--------|------|
| **VOLTA** | Pulse Core | EDM | battle | 城市电网夜班调度员 | 胸口四层共振菱形徽记 + 静电炸开的发 | `#E23D3D` |
| **STATIC** | Night Grid | Hip-hop | night-drive | 深夜街区信使 | 兜帽 + 头戴耳机 + 斜挎信使包 | `#6E2426` |
| **PRISM** | Glass Rim | Pop | groove | 玻璃幕墙光影剪辑师 | 护目镜 + 反光刮板（不是武器，是工具） | `#E4D8C4` |
| **EMBER** | Afterhours Lane | R&B | chill | 打烊后还在弹 Rhodes 的酒吧乐手 | 翻起的键盘盖 + 一杯冷掉的咖啡 | `#B0765A` |
| **RIVET** | Chrome Yard | Rock | battle | 废旧车间的吉他改装师 | 腰间工具带 + 缺一角的拨片挂坠 | `#8C8079` |
| **GLIDE** | Slide District | EDM | battle | 天台之间滑索穿行的信使 | 滑索手套 + 飘起的长围巾 | `#FFB020` |
| **HALO** | Skyline Hook | Pop | groove | 城市天际线观测员 | 肩上停着的机械信鸽 + 测距仪 | `#5B8DEF` |

### 2.2 统一规则（每个角色都遵守）

**共有的视觉语言**（与 `RESONANCE-VISUAL-PLAN.md` §3 一致）：
- 平涂 + 硬边 + 粗描边（2-3px 纯黑墨线）
- 四色结构：墨黑底 `#12100F` + District 主色 + 米白 `#F2E4C9` + 琥珀 `#FFB020`
- 头后**四层共振菱形**（自创 motif，永远出现在"声源"位置：胸口/耳机/乐器/肩上信鸽）

**共有的人设约束**（IP 纪律）：

> **v2（2026-08-30）**：画风改为 **anime 立绘**（见 [`BEATSCAPE-CHARACTER-ART-BRIEF.md`](./BEATSCAPE-CHARACTER-ART-BRIEF.md)），
> 角色**要露脸**。因此差异化的着力点从「藏脸」转移到「原创脸」——这是本次调整的核心，
> 风险敞口相应变大，盲测（§5 / RESONANCE-BLINDTEST 角色关）从建议升级为**硬性放行关卡**。

- ~~脸在阴影里~~ → **脸要画，但必须是原创设计**：不得靠近任何既有角色的五官、发型、配色组合
- 标志物 = **职业工具**，**不是** 武器、徽章、面具、塔罗牌
- **不穿校服、不穿制服**、不戴面具、不披披风
- 体型可辨（broad/lean/tall/compact/seated）—— 64px 剪影必须能区分
- **发型是第一识别点**：anime 立绘靠发型剪影建立记忆点，每个角色的发型必须互相区分

### 2.3 Do / Don't（每个角色的"能"与"不能"）

| Do | Don't |
|----|-------|
| 标志物 = 工具（刮板、耳机、围巾、拨片、信鸽、咖啡） | 武器（刀、枪、棍、棒球棒） |
| 剪影差异优先 | 让脸可读（不出现眼/鼻/嘴） |
| District 配色严格 | 换 District 色 |
| 共振菱形在声源位置 | 用面具、塔罗、动物头像 |
| 身体可带静电/带器械的暗示 | 任何可识别的"披风+面具+紧身衣"组合 |
| 中文/英文混合的世界观文案 | 日文假名/拟声词/JRPG 视觉符号 |

### 2.4 角色 × 音乐的咬合（这是这套结构最值钱的地方）

85 首曲库 + 7 角色 = 已有结构性资产，**不浪费**：

| 角色 | 锚定 District | 现有曲目数 | 招牌曲候选 |
|------|---------------|-----------|------------|
| VOLTA | Pulse Core | 20 首 EDM | bs-s4-06 Resonance Overload（battle hard）|
| STATIC | Night Grid | 17 首 Hip-hop | bs-s3-12 Trap Grid（battle，gimmick 强烈）|
| PRISM | Glass Rim | 17 首 Pop | bs-s4-08 Crimson Hookline（groove，封面有棱镜感）|
| EMBER | Afterhours Lane | 14 首 R&B | bs-s6-28 Amber Afterhours（literal 名字契合）|
| RIVET | Chrome Yard | 17 首 Rock | bs-s5-10 Iron Boulevard（命名 + 职业直接咬合）|
| GLIDE | Slide District | EDM 子集 | bs-s5-05 Chrome Vector（slide 曲，名字含 motion）|

## 3. 差异化硬约束（升级版）

人物 IP 让 `Tetris v. Xio` / `Spry Fox v. Lolapps` 那一类 look-and-feel 风险被**显著放大**——从「UI 看起来像」变成「商业衍生品在搭便车」。所以差异化从"建议"升级为"硬约束"。

### 3.1 角色层（新增）

> **v2（2026-08-30）画风改 anime，露脸**：约束从「藏脸」改为「原创脸」。
> 完整美术规范见 [`BEATSCAPE-CHARACTER-ART-BRIEF.md`](./BEATSCAPE-CHARACTER-ART-BRIEF.md)。

- **脸要画，但必须是原创五官**——不得靠近任何既有角色；不用「酷、沉默、戴面罩的少年」这类被用烂的 archetype，改用**职业身份**建立气质
- **发型是第一识别点**：每个角色的发型剪影必须互相区分，且在 64px 下可读
- **不画面具 / 面罩 / 眼罩**：这是最强识别符号，用了等于昭告在抄
- **不画武器**：道具必须是工作工具，不是攻击性物件
- **不画制服 / 校服 / 披风 / 紧身衣**：服饰只有通用职业装（工装夹克 + 长裤 / 信使包 / 马甲）
- **不用「手套 + 靴子 + 紧身衣」套装语汇**：这是特定作品的造型语法
- **不发 IP 文字 logo**：角色代号不作为 logo 出现（避免与既有作品 logo 撞视觉）
- **不背故事道具**：无枪/刀/行李箱/雨伞/棒球棒这类有故事性的物件
- **不用怪盗 / 义贼 / 觉醒 / 叛逆叙事**：主题层也要拉开

### 3.2 沿用（来自 `RESONANCE-VISUAL-PLAN.md` §1.1）

- 不出现 Persona / ペルソナ / Atlus / P5 / 女神异闻录 字样
- 不出现任何具体角色（Joker、怪盗团等）
- 不借用人格面具 / 塔罗 / 天鹅绒房间 motif
- 字体只用 OFL / Apache
- 不引入日文假名 / 二次元拟声词

### 3.3 衍生品层（新增 — 重要）

**`Tetris v. Xio` 判例的直接教训**：被告的素材全部新画，仍被判侵权。衍生品必须经由 `docs/RESONANCE-BLINDTEST.md` 的盲测（不玩日式 RPG 的观察者，**任一人识别出来源作品即不通过**），且按品类分级：

| 品类 | 盲测闸门 | 额外要求 |
|------|----------|----------|
| 数字壁纸 / 头像 | 通过即可 | 无 |
| 贴纸 / 表情 | 通过即可 | 无 |
| 印花 T 恤 / 帆布袋 (POD) | 通过 | 印刷文件 300dpi + CMYK 出片确认 |
| 徽章 / 亚克力立牌 | 通过 | 一次性开模，不可堆码 |
| 手办 / 模型 | 通过 + 法律复核 | **必须**独立法律意见 |

## 7. 一句话给团队

> 音乐 IP 用来让 BeatScape 听上去**像 BeatScape**；人物 IP 让 BeatScape 看上去**像 BeatScape**。两件事都不靠碰瓷，靠**自己那套可识别的语义**——共振菱形、District 配色、7 个角色各自的职业与发型剪影。差异化是最硬的护城河。

**关于「像不像某款 JRPG」这个问题，内部统一口径**：

- 我们要的是 **anime 画风**——这是几十年的公共技法，谁都能用，尽管放开手脚。
- 我们不要的是 **任何可识别的既有表达**——面具、校服、塔罗、那个特定的「酷」的 archetype。
- 区分点：**借技法，不借表达**。识别度从共振菱形 + District 配色 + 职业道具里长出来，
  不从「红黑很酷」这件事本身长出来。
- 拿不准就跑盲测。观察者的第一反应是唯一的裁判，我们的自我论证不算数。
