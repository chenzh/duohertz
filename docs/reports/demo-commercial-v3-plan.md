# Demo 商用级改造计划 v3

**日期：** 2026-08-23  
**版本：** v0.1（规划稿）  
**前置：** [demo-commercial-plan.md](./demo-commercial-plan.md) Phase A–D 已全部落地  
**目标：** 将 Demo 从「能用的 API 试用页」升级为 **对外可售卖信心的产品演示站** —— 访客在 30 秒内建立信任，在 5 分钟内完成「听 → 试 → 想接入」的完整转化路径

---

## 1. 为什么 v2 仍显「简单」

v2 解决了 **功能完整** 与 **路演不翻车**，但离 **商用级产品演示** 仍有明显落差：

| 观感维度 | v2 现状（2026-08-23） | 客户/投资人心理预期 |
|----------|----------------------|---------------------|
| **首屏冲击力** | 文字 Hero + `♪` 占位 Logo | 品牌识别、产品截图/动效、社会证明 |
| **产品叙事** | 一句副标题 | 痛点 → 方案 → 差异化（本地 / 双引擎 / 合规） |
| **创作体验** | 原生表单 + 下拉框 | 向导式流程、智能提示、歌词/提示词辅助 |
| **输出呈现** | 假波形（Canvas 正弦）+ 原生 `<audio>` | 真波形、封面占位、全屏试听、A/B 对比 |
| **作品感** | session 任务列表（无封面/标签） | 作品库网格、按场景筛选、精选样例墙 |
| **信任背书** | 页脚两行许可 | 架构图、数据不出域、性能数字、部署形态 |
| **转化路径** | 底部集成折叠面板 | 定价预览、PoC 清单、联系/试用 CTA、案例场景 |
| **演示形态** | `?demo=1` 略隐藏 job_id | 全屏路演台、自动旁白脚本、遥控/键盘切换 |
| **移动端** | 能看能用 | iPad 横屏像「展台 App」，手机可看精选样例 |

**结论：** v2 是合格的 **工程师 Demo**；v3 要变成合格的 **销售 Demo**。

## 2. 产品定位（Demo v3）

### 2.1 一句话

> **MusicSaas Demo = 本地双引擎音乐 API 的「产品官网 + 互动沙盒」**，让集成方与决策者相信：这套方案能落地、能演示、能接进他们的产品。

### 2.2 目标用户

| 角色 | 关注点 | v3 要回答的问题 |
|------|--------|----------------|
| **技术集成方** | API 形态、延迟、稳定性 | 怎么调？多快？挂了怎么办？ |
| **产品/策划** | 场景、质量、可控性 | 游戏 BGM 和人声分别什么水平？ |
| **决策者** | 合规、成本、部署 | 数据在哪？要什么硬件？怎么卖？ |
| **路演主持** | 流畅、可控、有兜底 | 5 分钟怎么讲？断网怎么办？ |

### 2.3 成功标准（可量化）

| 指标 | v3 目标 |
|------|---------|
| 首屏停留理解 | 30s 内说出「本地 API、双引擎、人声+BGM」 |
| 首次试听 | 进入页面 **无需点生成** 即可听到 1 条精选样例 |
| 首次自助生成 | 预设 → 生成 → 播放 < 3 分钟（含 MLX 等待） |
| 投屏路演 | 15 分钟单页/多 Tab 讲完，主持人无需开 IDE |
| 集成转化 | 80% 访客能在页内找到可复制的 API 示例 |
| 视觉对标 | 内部评审：「不像内部工具，像可对外展示的 SaaS 试用」 |

### 2.4 明确不做（仍属 SaaS v1.0）

- 真实注册登录、多租户、计费扣款
- 永久云端作品库与社交 Feed
- 用户上传参考音频、分轨编辑器
- Demo 内嵌生产 API Key
- 替代官网的完整 CMS（v3 仍是静态 Demo + BFF）

## 3. 信息架构（v3 目标）

由 **单页堆叠** 升级为 **「着陆 + 沙盒」双区**，仍保持 SPA、无重型路由框架：

```text
┌─────────────────────────────────────────────────────────────────────────┐
│  Nav: Logo · 产品 · 场景 · 定价预览 · 文档 · [立即体验] · 中/EN · 健康灯   │
├─────────────────────────────────────────────────────────────────────────┤
│  §1 着陆区（Landing）— 默认首屏，向下滚动进入沙盒                              │
│  ┌───────────────────────────────────────────────────────────────────┐  │
│  │ Hero 动效/视频 · 三卖点卡片 · 双引擎对比条 · 「30s 试听」播放条      │  │
│  │ 社会证明：M1 基准数字 / 部署形态图标（Mac MLX · 私有云）            │  │
│  └───────────────────────────────────────────────────────────────────┘  │
│  §2 场景橱窗（Showcase）— 精选 6–8 条预置作品，可点即播                    │
│  §3 架构与信任（Trust）— 交互架构图、数据流、许可摘要、硬件建议              │
├─────────────────────────────────────────────────────────────────────────┤
│  §4 创作沙盒（Playground）— 现有 v2 双栏，增强版                          │
│  场景 Tab · 预设 · 表单 · 时间线 · 真波形播放器 · 任务网格 · 集成面板       │
├─────────────────────────────────────────────────────────────────────────┤
│  §5 转化区（Convert）— 定价预览卡片 · PoC 清单 · API 文档 · GitHub        │
├─────────────────────────────────────────────────────────────────────────┤
│  Footer: 合规 · 版本 · 局域网 URL · 路演快捷键说明                         │
└─────────────────────────────────────────────────────────────────────────┘

URL 模式：
  /demo/              完整站（着陆 + 沙盒）
  /demo/?playground=1  直达沙盒（老客户/集成方）
  /demo/?present=1    全屏路演（隐藏 Nav/Footer，大播放器）
  /demo/?dev=1        开发者信息（保留 v2）
```

## 5. 分阶段路线图

### Phase E — 产品门面（P0，~4d）

**目标：** 打开链接像「产品官网」，而不是工程验收页。

| ID | 任务 | 交付 |
|----|------|------|
| E-1 | **品牌包** | Logo SVG、产品色扩展、favicon、`og:image` 占位 |
| E-2 | **Landing Hero** | 标题/副标题/三卖点；CTA「立即体验」平滑滚动到沙盒 |
| E-3 | **Showcase 橱窗** | `showcase.json` + 6–8 条精选音频（游戏 3 + 人声 3 + 主题曲 2） |
| E-4 | **Hero 试听条** | 首屏 30s 循环试听，无需生成 |
| E-5 | **导航栏** | 固定顶栏：锚点跳转（产品/场景/体验/文档） |
| E-6 | **真波形 v1** | `AudioPlayer` 用 Web Audio 解码绘制真实 peaks |
| E-7 | **验收** | `acceptance-demo-web.py` 增加 E-01~E-04（Landing/Showcase/锚点/试听） |

**验收：** 新访客不点「生成」也能在 10s 内听到音乐并理解产品定位。

---

### Phase F — 沙盒体验升级（P1，~5d）

**目标：** 创作与输出区达到「可给客户操作」的精致度。

| ID | 任务 | 交付 |
|----|------|------|
| F-1 | **Playground 分区** | `?playground=1` 或滚动进入；与 Landing 样式层级区分 |
| F-2 | **表单向导** | 3 步 Stepper：选场景 → 填参数 → 确认生成；保留高级模式一键展开 |
| F-3 | **Prompt 辅助** | BGM：标签 chips 追加；人声：歌词模板插入（Verse/Chorus） |
| F-4 | **作品网格** | 替换纯列表 `TaskCard` → 封面渐变 + 元数据 + hover 播放 |
| F-5 | **引擎对比卡** | 静态 A/B 播放器：同场景 ACE 人声 vs SA3 BGM 各一条 |
| F-6 | **进度增强** | 时间线 + 已等待秒数 + 队列提示文案（基于 status + 经验值） |
| F-7 | **空状态插画** | 输出区 idle 用场景插画 +「选预设或听橱窗」引导 |
| F-8 | **表单草稿** | `localStorage` 自动保存，刷新恢复 |

**验收：** 非技术人员可独立完成一次生成；完成后愿截图分享。

---

### Phase G — 信任与转化（P2，~4d）

**目标：** 支撑销售对话与 PoC 决策，而非仅技术验证。

| ID | 任务 | 交付 |
|----|------|------|
| G-1 | **Trust 架构图** | 可点击 SVG：Client → Gateway → Workers → MLX |
| G-2 | **性能看板** | 从 `/demo/meta` 扩展：`benchmark`（M1 人声 ~3s、BGM 目标值） |
| G-3 | **部署形态卡** | Mac MLX / Docker 规划 / 私有云 — 图标 + 一句话 |
| G-4 | **定价预览** | 三档占位（Developer / Team / Enterprise），明确「Demo 不计费」 |
| G-5 | **PoC 清单** | 可打印 Markdown 渲染：硬件、网络、验收项、预计 2 周 |
| G-6 | **合规深化** | 链 COMPLIANCE + 模型许可折叠 FAQ（5 问） |
| G-7 | **路演模式 v2** | `?present=1`：全屏、大播放器、步骤点、按 `P` 显示讲稿备注 |
| G-8 | **讲稿脚本** | `docs/DEMO_SCRIPT.md` + `scripts/demo-present.sh` 支持 `--present` |

**验收：** 销售可用同一链接完成「讲产品 + 现场生成 + 给 API 文档」。

---

### Phase H — 增长与工程化（P3，~4d，可选）

| ID | 任务 | 交付 |
|----|------|------|
| H-1 | **深链分享** | `?job={id}` 只读播放（BFF 校验 + 过期提示） |
| H-2 | **Onboarding** | 3 步 Coach Mark（橱窗 / 预设 / 集成面板） |
| H-3 | **键盘快捷键** | `G` 生成、`Space` 播放、`?` 帮助浮层 |
| H-4 | **Playwright 视觉** | 截图基线：Landing、Playground、Present |
| H-5 | **性能预算** | 首屏 LCP < 2.5s（懒加载音频、代码分割） |
| H-6 | **分析占位** | 匿名事件：`demo_play_showcase`、`demo_job_completed`（仅 console/可选 POST） |

## 7. 技术方案

### 7.1 前端结构（v3 建议）

```text
apps/demo/src/
  sections/           # Landing, Showcase, Trust, Playground, Convert
  components/         # 复用 v2 + WaveformReal, ShowcaseCard, Stepper...
  content/            # zh/en 着陆与定价文案
  hooks/              # useWaveform, useOnboarding, usePresentMode
  lib/                # integrationSnippets（已有）
  presets/            # 表单预设（已有）
  styles/             # tokens v2（字体层级、动效、渐变）
  App.tsx             # 编排 sections + URL 模式
```

**依赖策略（克制）：**

| 包 | 用途 | 阶段 | 备注 |
|----|------|------|------|
| 无新增路由库 | 锚点 + search params | — | 保持 Vite SPA |
| `wavesurfer.js` | 真波形（可选） | E/F | 优先 Web Audio 自绘，包体超 80KB 再懒加载 |
| 轻量动效 | CSS `@keyframes` 为主 | E | 避免重型动画库 |

### 7.2 BFF / Gateway 扩展

| 端点 | 说明 | 阶段 |
|------|------|------|
| `GET /demo/meta` | 扩展：`benchmark`, `showcase_version`, `features[]` | G |
| `GET /demo/api/v1/jobs/:id` | 深链只读（H，可选鉴权） | H |
| 静态 `showcase/*` | 大图/音频 | E |

### 7.3 设计系统 v2（在 tokens.css 上演进）

| 令牌 | v2 | v3 |
|------|----|----|
| 字体 | system-ui | 标题：`DM Sans` 或系统 display；正文保持 system-ui |
| 背景 | 纯色暗色 | 渐变 mesh 背景 + 玻璃卡片 `backdrop-filter` |
| 圆角 | 8–12px | 卡片 16px，按钮全圆角 pill |
| 动效 | 150ms | 页面 section `fade-up` 进入；播放器 300ms ease |
| 场景色 | 紫/粉 | 增加渐变轴：游戏 `#7c3aed→#2563eb`，人声 `#db2777→#f97316` |

### 7.4 测试

| 层级 | 范围 |
|------|------|
| `acceptance-demo-web.py` | E-01~E-04、保留 D-* 回归 |
| Playwright | F-8 后加视觉快照；Present 模式 smoke |
| 人工 | 路演彩排（附录 B） |

## 9. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 范围膨胀成完整 SaaS | 本计划 §2.4；H 阶段全部可选 |
| 真波形性能差 | 预计算 peaks JSON；长音频只绘前 60s |
| 着陆区拉长首屏 | 试听条懒加载；Landing 与 Playground 代码分割 |
| Showcase 音频质量不稳 | 人工听审 + 固定种子复现脚本 |
| 双语文案拖慢 | 先中文落地，英文化同 PR 跟进 |
| SA3 数字缺失 | Trust 区标注「BGM 基准待填」，不造假 |
