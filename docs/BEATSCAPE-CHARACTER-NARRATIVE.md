## 0. 最重要的一句话（先读这段）

我们要的不是"一个像某款 JRPG 的角色群"，而是一套**从 BeatScape 自身长出来的原创叙事**。

判断标准同 Art Brief §0：不是「我们有没有抄」，而是 *Tetris Holding v. Xio Interactive*（2012）——整体 look and feel 容易被误认即侵权。所以本 Bible 的叙事结构**主动不借** P5 的「认知元宇宙 / 人格面具召唤 / 怪盗盗窃 / 塔罗命运 / 校服觉醒」等任何既有一揽子设定，改用我们自己的产品前提（城市声音 = 基础设施）去长。

**叙事动作 = 调音 / 手艺，不是战斗 / 偷窃 / 召唤。**

## 1. 世界观（原创 · 零盗版风险）

**Scape City** 是一座把"声音"当基础设施运营的城市。每个 District 不靠电网或水管维持，而靠一段特定的**共振频率**维持运转——灯要跟着频率亮、信号要跟着频率通、连街区的"气氛"也是频率的副产品。

维系全城频率的隐形场叫 **the Scape（声景场）**。它平时没人察觉，只在某个 District 的频率**失谐（out of phase）**时显形：灯乱闪、信号噪、气氛塌。

七个角色是各自 District 的 **Tuning Keeper（共振守护者）**。他们不战斗、不偷、不召唤任何东西，而是用**本职的手艺 / 工具**把频率调回正相位。这把"打歌"和"叙事"焊死：**玩家每 play 一个 District，就是在帮那位 Keeper 把那段频率调稳**——游戏机制即叙事动作。

> 为什么无版权风险：世界是字面意义的城市（不是心理空间 / 元宇宙），角色用现实职业工具（不是武器 / 面具 / 召唤物），冲突是"频率失谐"（不是善恶对决 / 盗窃）。全部原创。

## 2. 核心术语表（统一用语，避免借用既有作品词汇）

| 词 | 含义 | 备注 |
|----|------|------|
| 共振（Resonance） | 角色与 District 频率同拍的状态 | 我们的核心词，对应产品名 BeatScape |
| 频率 / 相位 | District 的运转参数 | 非音乐术语独占，城市基建隐喻 |
| 失谐（Out of phase） | District 频率偏移，故事触发事件 | 冲突来源，非"反派" |
| Drop | 多 District 频率对齐时全城共享的底鼓时刻 | 集结 / 高潮，非"觉醒" |
| 共振菱形 | 四层同心菱形，中心实心，**出现在声源位** | 唯一统一标志（Art Brief §3） |
| District | 7 个城区，各有配色 / 曲风 / Vibe | 已落地于 catalog.json |

**禁用叙事词**（红线）：觉醒、叛逆、怪盗、义贼、盗窃、秘密结社、面具、人格、召唤、塔罗、牌阵、元宇宙、认知世界、校服、教室。

## 3. 版权护栏（本 Bible 的硬约束）

### 3.1 我们**不借** P5 的结构（清单）

| P5 用过的结构 | 我们换成 |
|------|------|
| 认知世界 / 元宇宙（心理空间） | 字面城市，声音即基础设施 |
| 人格面具 / 召唤同伴 | 不召唤，只用本职工具调音 |
| 怪盗 / 盗窃 / 反抗组织 | 无盗窃、无义贼、无"觉醒/叛逆"叙事 |
| 塔罗 / 牌阵（角色 & 命运系统） | 共振相位（连续量，非牌阵） |
| 校服 / 教室设定 | 职业人，工装非制服 |
| 面具视觉标志 | 共振菱形（自有 MOTIF） |
| 具体神话 / 宗教体系 | 不绑定任何真实神话 |

### 3.2 我们**原创主张**的东西

- **共振菱形**：全系列唯一统一标志，已写入 Art Brief §3，属 BeatScape 自有语义。
- **7 个代号**（VOLTA / STATIC / PRISM / EMBER / RIVET / GLIDE / HALO）：原创代号即角色公开 handle（类似 DJ 名），非既有作品名。
- **虚构城市与 District**：不对应任何真实城市地标（Art Brief §1 背景规则）。
- **叙事动作 = 调音 / 手艺**：与战斗 / 偷窃 / 召唤彻底切割。

> 结论：结构层 100% 原创，仅 anime **技法层**（赛璐璐 / 线稿 / 夸张发型）自由使用（见 Art Brief §1）。

## 4. 七角色叙事弧光（各 3 拍：呼频异常 → 手艺介入 → 归处）

> 每角色身份 / District / 主色 取自 Art Brief §4。代号不作为 logo 使用（Art Brief §4 注）。

### VOLTA · Pulse Core · `#E23D3D` · 城市电网夜班调度员
- **呼频**：Pulse Core 的供电频段开始"布朗闪烁"——全区的灯随一个听不见的节拍明灭，居民以为电网故障。
- **手艺**：她顺着胸口的共振菱形，把高压电重分配成一段"可被聆听的频率"；只要让电流跟着菱形共振，电网反而更稳。
- **归处**：她第一次"听见"电网——它不是机器，是城市的脉搏。她把夜班调度台改成一座小型共振台，从此 Pulse Core 的歌由她亲手调出。

### STATIC · Night Grid · `#6E2426` · 深夜街区信使
- **呼频**：Night Grid 的监控频段被一种低频噪声淹没，街灯乱闪，像夜里有什么"睁了眼"。
- **手艺**：她把磁带机接进频段，一格一格重录"清净"——用跑单时记下的城市白噪覆盖噪声。
- **归处**：她发现噪声来自自己不肯睡下的执念（怕错过某通求救信）。她学会把信使包留在楼下，允许自己"离线"一晚；Night Grid 第一次安静下来。

### PRISM · Glass Rim · `#E4D8C4` · 玻璃幕墙光影剪辑师
- **呼频**：Glass Rim 的折射阵列错位，整片幕墙把光打成刺眼碎片，行人睁不开眼。
- **手艺**：他用反光刮板重排棱镜阵列，让光"穿过"而非"反弹"，把每道入射重新校直。
- **归处**：他领悟"光要透过去才美，不该被占有"——把幕墙调成随路人移动的柔光，玻璃区成了城市的棱镜公园。

### EMBER · Afterhours Lane · `#B0765A` · 打烊后弹 Rhodes 的酒吧乐手
- **呼频**：深夜酒馆的暖光在熄，最后一桌客人走后，吧台的共振也快散了。
- **手艺**：他用一杯冷掉的咖啡当阻尼，把 Rhodes 尾音拉长，让吧台共振"留"住最后一束暖光。
- **归处**：他明白酒馆的意义不是卖酒，是"有人愿意在末班后停留"。Afterhours Lane 的歌，是给所有晚归人的。

### RIVET · Chrome Yard · `#8C8079` · 废旧车间吉他改装师
- **呼频**：Chrome Yard 的旧机械场频率卡死，像一首歌卡在某一拍。
- **手艺**：她把卡死的机械逐件拆开，用工具腰带重组成新传动，让节拍重新流动。
- **归处**："坏掉的东西也能重组出新的节拍"——她把废场改成开放工坊，任何卡住的旋律都能来这里被"拧"活。

### GLIDE · Slide District · `#FFB020` · 天台间滑索穿行的信使
- **呼频**：Slide District 的滑索场速度失谐，冲出去的人总在半空"顿"一下。
- **手艺**：他重画一条顺着城市风的动线，把长围巾当测风旗，找到让速度连续的弧。
- **归处**：他懂了"流动不是快，是下一拍永远接得上"——Slide District 成了全城最快也最稳的转运线。

### HALO · Skyline Hook · `#5B8DEF` · 城市天际线观测员
- **呼频**：天台的观测信号中断，制高点的共振掉线，整片天际线"暗"了一格。
- **手艺**：他放出机械信鸽沿楼宇重连测距，把 Skyline Hook 的频段重新锚在最高处。
- **归处**：他明白俯瞰不是为了远离，是为了在所有人迷路时指明"哪盏灯还亮着"。Skyline Hook 是城市的灯塔频率。

## 5. 共享集结线（原创 ensemble · 非 persona 合体）

**全城 Drop（City-wide Drop）**：当七个 District 的失谐**同时**尖峰（例如一次全城停电殃及所有频段），七人第一次不再各自为战。他们把各自的共振菱形调到同一相位，城市从静默里"drop"出一段所有人共享的底鼓——七条线合成一句。

这是 BeatScape 的"集结"：没有任何召唤 / 合体 / 怪盗语汇，只是七个 Keeper 把频率对齐。可作为版本节点、联动活动、或角色群像海报的叙事锚点。

## 6. 视觉语言方向（如何达到 P5 级观感 · 原创等价）

用户希望观感**尽量贴近 P5 的抓人**，但只能原创去够。把 P5 的"抓人"拆成两层：

| P5 抓人来源 | 层 | 我们做法 |
|------|------|------|
| 高对比平涂 + 粗肯定线 + 动态姿势 + 大色块 | 技法（自由） | **直接沿用**（Art Brief §1） |
| 统一标志（面具 / 字体炸裂） | 表达（红线） | **共振菱形**作全系列统一标志（自有 MOTIF，替面具） |
| 校服剪影 | 表达（红线） | **职业工装剪影**（替校服，且比校服更原创） |
| 红黑标志性配色 | 表达（红线） | **7 District 锁定色系**（替红黑） |
| UI 涂鸦 / 文字炸裂背景 | 表达（红线） | **每角色"共振场"图形背景**（原创，见下） |

### 6.1 原创图形系统：共振场背景
给每个角色一套统一的**共振场**背景模板（替代 P5 的 UI 涂鸦）：半调网点 + 四层菱形向外扩散 + District 主色辉光。模板统一、配色各异 → 七张图"成一系列"且完全原创，不蹭任何作品排版。

### 6.2 系列感锁定清单（给画师 / 生图）
- **姿势库**：每人 1 个主导动态（VOLTA 抬手调电、STATIC 挎包侧身、GLIDE 前冲、HALO 远望…），避免各画各的导致不成系列。
- **线宽比**：外轮廓粗、内构线细，七张一致。
- **赛璐璐阶数**：统一 2–3 阶硬边，不用柔光 / 渐变（Art Brief §1）。
- **菱形固定位**：永远在"声源位"（胸口 / 耳机 / 工具 / 肩上的信鸽），见 Art Brief §3。
- **背景系统**：统一共振场模板，仅换 District 色。

### 6.3 更严红线审查（因要更接近 P5 观感，混淆风险↑）
在 Art Brief §5 基础上**追加**自查：
- [ ] 不出现任何 P5 式文字炸裂排版（如 "ALL OUT" 类大标题 splash）
- [ ] 群像构图不参考任何既有作品群像站位
- [ ] 不以红黑作为主对比（用 District 主色）
- [ ] 盲测门槛保持"**任一人**说出源作即 fail"（Art Brief §5.2）
- [ ] 出图后跑一次反向比对 / 盲测，确认无人联想到 P5 或任何 JRPG

> 越想贴近观感，越要靠"原创等价"拉开，而不是靠"红黑很酷"本身（Art Brief §2.2）。

## 7. 可衍生性（Derivability）

- **64px 剪影测试**（Art Brief §5.1）：每个角色靠发型 + 职业剪影 + 菱形位置在 64px 下可区分，是衍生品硬约束。
- **符号一致**：共振菱形是唯一跨角色标志，商品（徽章 / 贴纸 / 立牌）只用它，不引入新符号。
- **叙事挂钩商品**：每个 District 的"频率故事"可对应一款实体（如 VOLTA 的调频台钥匙扣、EMBER 的留灯杯）——故事即产品语境，无第三方 IP。
