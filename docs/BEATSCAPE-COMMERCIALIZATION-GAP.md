# BeatScape 商业化差距分析（Commercialization Gap Analysis）

> **文档定位**：回答一个问题——**从「可玩的免费游戏」到「能合法收钱并可持续运营的产品」，还差哪些东西**。
> **依据**：`apps/beatscape/PRD.md`（实现真值版，2026-08-30）· `docs/PRD-BEATSCAPE.md` v1.9.3 · `docs/BEATSCAPE-IP-STRATEGY.md` · `PRD.md` §13/§14/§21 · `SESSION.md` · 代码与 dist 实测（2026-08-30）。
> **口径**：本文只做差距盘点与路径建议，**不修改任何产品承诺**；拍板后需同步修订的文档在 §6 列明。所有成本均为**量级估算**，非报价。

---

## 0. TL;DR

游戏本体（85 首自有曲库、双资产、判定内核、Local Board）已经**超出可玩标准**，但距离商业化有**四层缺口**：

1. **上线闸门未过**——50 首耳检、差异化盲测、CF 重部署、SA3 商用登记，一个都没完成；不先过闸门，任何收费动作都是品牌自杀。
2. **变现基础设施为零**——无账号体系、无服务端、无支付通道、无云存档；目前整站纯前端 + localStorage，一分钱都收不了。
3. **变现模式未拍板**——产品 PRD 白纸黑字承诺「永久零广告、零内购、零付费」（§9.5/§13.3），而 IP 战略的变现路径（衍生品/角色商店/订阅引流）要求修订该承诺或完全绕开游戏内变现。**这是必须先拍板的战略矛盾。**
4. **增长与引流闭环断裂**——85 首「流媒体完整版」资产的唯一变现出口（`StreamFullCTA` → MusicSaas App）在线上实际显示 **"App link coming soon"**（实测：0/85 首 `stream_app_url`，dist 未烘焙任何 App 域名，且 MusicSaas 流媒体 App 本身尚不存在）；SEO 无 sitemap/robots；Reddit 发布指南停留在 35 首时代。

**差距总量：7 域 34 项**（P0 ×9 · P1 ×14 · P2 ×11），其中 **5 项是「其他项的前置」**（§4 依赖图加粗项）。

| 优先级 | 数量 | 定义 |
|--------|------|------|
| **P0** | 9 | 不做就不能收费 / 不能宣称上线 / 法律裸奔 |
| **P1** | 14 | 直接决定收入与留存曲线 |
| **P2** | 11 | 提升天花板，可随收入再投入 |

## 1. 现状基线

### 1.1 已经有的（商业化的原料）

| 资产 | 状态 | 商业化意义 |
|------|------|------------|
| 游戏本体 | 67/67 测试绿 · 60fps · 全端 | 产品载体成立，无需重写 |
| **音乐 IP** | 85 首母带 + 双资产（切片 60–120s / 完整版 180–216s）· 引擎许可干净（SA3 Community / ACE-Step MIT） | 自有产品内用无风险；**对外授权被战略禁止**（纯 AI 编曲不受著作权保护，IP-STRATEGY §1.1） |

| 合规底子 | 零账号零收集 · Privacy/Terms 页 · 全 OFL 字体 · AI Original 话术 | 出海合规起点高于多数独立产品 |

| 缺位 | 实测证据 |
|------|----------|
| 服务端（任何形式） | 排行榜纯 localStorage；无账号、无 API 调用、无支付 |

## 2. 变现模式抉择（先于一切执行）

### 2.1 核心矛盾

`docs/PRD-BEATSCAPE.md` §9.5 / §13.3：**「永久零广告、零弹窗、零内购诱导」**——这是当年打 Reddit 口碑的产品承诺。而商业化必然意味着某处收钱。四条路径对这个承诺的冲击完全不同：

### 2.2 四条路径对比

| 路径 | 形式 | 对「零广告零内购」承诺 | 收入天花板 | 依赖 | 评估 |
|------|------|------------------------|-----------|------|------|
| A. 游戏内广告 | 激励视频/插屏 | **直接违背**，且毁 Reddit 口碑基本盘 | 低（音游 eCPM 差） | 无 | ❌ **永久排除**（与 §9.5 保持一致） |
| B. 游戏 IAP | 解锁曲包 / 角色皮肤 / 完整版谱面 | 需修订承诺（可保留「核心免费无广告」口径） | 中 | 收款主体 + 账号 + 商店 UI + 服务端校验 | ⚠️ 可选，建议**仅 cosmetic**（角色形象/特效/主题），不卖判定优势 |
| C. IP 衍生品 | 数字周边（壁纸/贴纸）→ POD 实物（T 恤/立牌） | **不触碰游戏承诺**（钱在游戏外收） | 中高（随 IP 势能） | **17 商标（P0）** + anime 立绘 + 盲测角色关 | ✅ **主路径之一**，IP 战略既定方向 |
| D. 订阅引流 | 游戏 → MusicSaas 流媒体（完整版 + 未来角色语音/互动音频） | **不触碰游戏承诺** | 高（持续性收入） | **流媒体 App/站点本身不存在**（最大单项缺口） | ✅ **主路径之一**，85 首双资产就是为此准备的 |

### 2.3 建议（供拍板）

**主组合 = C + D，B 作为二期可选项，A 永久排除。** 逻辑：

- 音乐 IP 的法律边界（不可对外授权/上架 Spotify 等）决定了**引流的唯一合法终点是自有产品**——所以 D 不是「可选项」而是 85 首完整版资产唯一的规模化变现出口；
- 人物 IP 的变现天然在游戏外（周边），游戏本身继续作为 **免费 IP 流量入口**，这反而让「零广告零内购」承诺从「限制」变成「品牌定位」；
- 若二期做 B，仅上 cosmetic 类（角色主题化 PlayField 皮肤），并在 Settings/商店明确「不影响任何判定与内容解锁」，然后修订 PRD §9.5 话术为「core game free forever · no ads · cosmetics only」。

## 4. 依赖关系（什么阻塞什么）

```text
【上线与宣称】
耳检(0-1) ─┐
盲测(0-2) ─┼─→ CF 重部署(0-3) ─→ Reddit 发布(5-2) = 「正式上线」
SA3 登记(0-4) ─┘（法律面）

【收钱的最短链】
经营主体(1-2) ─→ 收款通道(2-1) ─┐
账号体系(2-2) ─→ 服务端(2-3) ───┴─→ 任何游戏内收费(B 路径) / 云存档(2-4) / 全球榜(2-5)
                                     （若只走 C+D，2-1/2-2/2-3 可整体推迟到二期）

【IP 变现的最短链】
17 商标(1-1) ─┬─→ 数字周边(4-3) ─→ POD 实物(P3)
anime 立绘(P1 项) ─┘   角色展示位(3-2) ─→ cosmetic 商店(3-3, 可选 B 路径)

【订阅引流的最短链】
流媒体终点(5-1) ─→ 85 首完整版资产变现 ─→ （未来）订阅/角色语音（root PRD §21.1 v0.2+）
```

**关键结论**：若拍板「C+D 优先、B 二期」，则 P0 从 9 项收窄为 **6 项**（0-1～0-4、1-1、5-1）+ 主体 1-2——**不需要先建账号/服务端/支付就能开始收钱**（周边与订阅都在游戏外）。

## 5. 分阶段路线图（建议）

### Phase 0 · 上线就绪（≈1–2 周，几乎零开发）

**范围**：0-1 耳检 · 0-2 盲测 · 0-3 重部署 · 0-4 SA3 登记 · 0-5 监控。
**DoD**：线上 = 85 首 + 质量闸门全绿 + 监控在位 → **获得「可对外宣称上线」的资格**。

### Phase 1 · 增长验证（≈1–2 月）

**范围**：5-2 Reddit 发布（85 首版）· 3-1 成就/段位 · 5-3 SEO · 5-5 漏斗埋点 · 4-1 月更机制落实 · 5-1 起步（MusicSaas 曲目页最小版）。
**DoD**：真实留存数据（D1 ≥ 基线待定）+ 每月新曲节奏跑通一轮 → **判断是否值得投入变现基础设施**。

### Phase 2 · 变现 MVP（≈2–4 月，与 Phase 1 部分并行）

**范围**：按 §2 拍板结果二选一——
- **C+D 线**：1-2 主体 → 1-1 商标首批 → 4-3 数字周边上架（游戏外收款）+ 5-1 流媒体页完善；

**DoD**：第一笔真实收入 + 徽章（首售/首订阅/首周边订单）。

**范围**：anime 立绘（人工画师）→ 角色关盲测 → 商标次批（角色代号）→ POD 实物 → 角色主题曲/语音（root PRD §21.1 v0.2+）→ 可选全球榜/赛事运营。
