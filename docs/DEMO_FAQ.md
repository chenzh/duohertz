# Demo FAQ（Trust 区摘要）

1. **数据会上传到云端吗？**  
   不会。Demo 走本地 Gateway + Worker，推理在己方 Mac。

2. **需要什么硬件？**  
   推荐 Apple Silicon Mac，16GB+ 内存；Gateway 可在任意 Node 20+ 机器。

3. **商用许可？**  
   ACE-Step 1.5 MIT；Stable Audio 3 Community License — 详见 `COMPLIANCE.md`。

4. **Demo 和正式 SaaS 区别？**  
   Demo 无账号/计费；SaaS v1.0 将增加多租户与作品库。

5. **集成要多久？**  
   REST API + 示例代码，通常 1–2 天可完成 PoC 调用。
